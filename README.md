# HanautAI

鼻歌だけで作曲できるブラウザベースのスタジオです。マイク入力からピッチを検出してノートに変換し、ピアノロールで編集できます。複数トラック、楽器変更、クオンタイズ、ループ再生、マスターエフェクトに対応しています。

## ローカルで起動

Node.js 22 以上を用意し、リポジトリのルートで次を実行します。

```sh
npm ci
npm start
```

ブラウザで <http://localhost:8088> を開きます。最新版の Chrome / Edge を推奨します。Web Audio とインポートマップに対応したブラウザが必要です。録音にはマイク権限と HTTPS または `localhost` が必要です。

Tone.js は `npm ci` でインストールされ、開発サーバーから配信されます。メロディ楽器の再生時は外部の [FluidR3 GM 音源](https://gleitz.github.io/midi-js-soundfonts/FluidR3_GM/) にアクセスするため、ブラウザが `gleitz.github.io` に接続できる必要があります。録音・ノート編集・MIDI書き出しに外部音源は不要です。

## 操作

- **録音**：開始時に選択していたトラックに、停止後にノートを追加します。
- **再生 / 停止**：停止すると再生位置は先頭に戻ります。ループ開始・終了は四分音符を1拍とする値で指定し、「ループ設定」で反映します。
- **ピアノロール**：クリックで追加、ドラッグで移動、右端ドラッグで長さ変更、右クリックで削除します。
- **保存 / 読込**：保存でプロジェクトのJSONをダウンロードし、同じブラウザのローカルストレージにも保存します。最後に保存したプロジェクトはページを開くと復元されます。明示的に保存するまで変更は永続化されません。新規作成・読込に成功すると現在の編集内容を置き換えます。
- **MIDI出力**：Standard MIDI File（`.mid`）をダウンロードします。メロディトラックは最大15本、ドラムはGM打楽器チャンネル（チャンネル10）を共有します。プロジェクトのエフェクト設定はMIDIには含まれません。

## テスト

```sh
npm test
npx playwright install chromium
npm run test:browser
```

Linuxでブラウザのシステム依存ライブラリも必要な場合は、`npx playwright install --with-deps chromium` を使用してください。ブラウザテストはローカルサーバーを自動起動し、実マイクや外部音源なしで実行できます。GitHub Actionsでも両方のテストを実行します。
