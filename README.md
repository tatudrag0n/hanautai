# HanautAI Mix Studio

ピッチ補正（Melodyne / Auto-Tune風）からビジュアルエフェクト（FFT EQ、コンプ、サチュレーション、ダブラー、空間XYパッド、マスターバス）までを直感的に操作できる、ブラウザ完結型のマルチトラックオーディオミキサーです。

## 主な機能

- **直感的ピッチ補正 (Pitch Studio)**
  - FFT高速YINピッチ検出 + 音符ブロブ自動セグメンテーション + キー・スケール自動判定
  - リアルタイム・ドラッグ音程補正、しゃくり分割（Split）、手描きカーブ（Draw）、スケール吸着
  - TD-PSOLA + 独立フォルマントシフト（-12〜+12半音）による高音質かつ自然な声質・音程補正
  - `Before / After` ワンクリック聴き比べ、ハモリ自動生成（+3度/+5度）
- **ビジュアル・エフェクトラック (Visual FX Rack)**
  - **4-Band EQ**: リアルタイムFFTスペクトラムを見ながらポイントを直接ドラッグ
  - **Comp & De-Esser**: 入出力カーブ＆リアルタイムGRメーター、ワンノブ簡単コンプ搭載
  - **Saturation**: 真空管 / テープ / エキサイター / Lo-Fi モードの波形可視化
  - **Doubler / Modulation**: ステレオ広がりを視覚的に調整
  - **Space XYパッド**: 1つの2Dパッドでリバーブ深さ × テンポ同期ディレイ量を操作
  - **信号順入替**: モジュールの接続順（例: EQ→COMP ↔ COMP→EQ）をボタンひとつで変更可能
- **プロ仕様ミキサーコンソール**
  - 各チャンネルのトリム、位相反転(`Ø`)、Send A/B、パン、M/S/R、dBフェーダー、ステレオPeak/RMSメーター
  - Master Bus（3-Band EQ、グルーコンプ、ステレオ幅、モノラルチェック、リミッター）
- **マルチトラック録音＆高品質WAV書き出し**
  - AudioWorkletによる低遅延マイクPCM録音（ライブチューナー & 任意ライブ補正モニター対応）
  - オーディオファイル（WAV / MP3 / OGG / FLAC等）のドラッグ＆ドロップ取り込み
  - `OfflineAudioContext` による全トラック・エフェクト込みWAVミックスダウン書き出し

## ローカル起動 & テスト

```sh
npm install
npm start       # http://localhost:5173 で開発サーバー起動
npm test        # DSP / 理論 / オーディオ変換のユニットテストを実行
npm run build   # TypeScript型チェック + 本番ビルド
```
