# HanautAI

鼻歌だけで作曲できるブラウザベースのスタジオです。

## 機能
- 鼻歌をMIDI化（マイク入力 → ピッチ検出 → ノート化）
- MIDIトラックの楽器変更（11種類）
- 複数トラック対応
- 微タイミング補正（クオンタイズ / マイクロ補正）
- 直感的なピアノロール編集（追加・移動・リサイズ・削除）
- ループ再生
- マスターエフェクト（リバーブ、ディレイ、コーラス、EQ、ディストーション、コンプレッサー）

## 起動方法
```bash
cd C:\root\work\hanautai
python -m http.server 8088
```
ブラウザで http://localhost:8088 を開いてください。

※ マイク入力には HTTPS または localhost が必要です。

## 操作
- ● 録音: 鼻歌を録音して現在のトラックにノート化
- ▶ 再生 / ■ 停止
- ピアノロール上でクリックでノート追加、ドラッグで移動、右端ドラッグで長さ変更、右クリックで削除
- 保存/読込でプロジェクト(JSON)を保存・復元
- MIDI出力で Standard MIDI File (.mid) を書き出し
